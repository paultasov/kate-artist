# KATE — художник

Портфолио-сайт для художницы Kate (K.A.T.U.S.H.A, Instagram [@katerinka19911](https://www.instagram.com/katerinka19911/)). Каталог работ, страница отдельной работы с полноразмерным просмотром, избранное, комментарии и заявки на покупку/вопрос — полностью на клиенте (MVP).

## Суть проекта

- **Frontend-only** Нет сервера и базы данных — все данные (пользователи, работы, избранное, комментарии, заявки) живут в localStorage браузера за общей абстракцией storage.
- **«Купить» ведёт в форму заявки**, а не в реальную оплату.
- Авторизация упрощённая и локальная: без email-подтверждения и без реальных гарантий безопасности.
- Данные не синхронизируются между устройствами и обнуляются при очистке хранилища браузера.

## Возможности

- Каталог работ с фильтрами по категориям и избранному, адаптивная сетка карточек.
- Слайдер лучших работ на главной с собственным переходом между слайдами.
- Страница отдельной работы: полноразмерный просмотр с зумом и перетаскиванием, похожие работы, комментарии.
- Избранное — с авторизацией, синхронизировано во всех местах интерфейса через общий стор.
- Заявка на покупку / вопрос по работе и отдельная форма обратной связи.
- Комментарии к работам с привязкой к автору.
- Простая локальная регистрация/вход.
- Заготовка админ-раздела (/admin) — пока не реализована.

## Архитектура

Приложение в client/ организовано по Feature-Sliced Design:

```
client/src/
  app/       — точка входа, роутинг, layout, сид-данные
  pages/     — страницы (главная, каталог, работа, избранное, контакты, настройки, админка)
  widgets/   — крупные составные блоки (шапка, подвал, слайдер, комментарии, похожие работы)
  features/  — пользовательские сценарии (избранное, заявки, комментарии, авторизация)
  entities/  — бизнес-сущности (работа, пользователь, комментарий, заявка, избранное)
  shared/    — переиспользуемые UI-компоненты, API-обёртка над localStorage, утилиты
```

## Быстрый старт

Всё выполняется из client/:

```bash
cd client
npm install

npm run dev        # локальный сервер разработки
npm run build      # прод-сборка в dist/
npm run preview    # предпросмотр собранного билда
npm run lint        # ESLint
npm run test         # Vitest, один прогон
npm run test:watch  # Vitest в watch-режиме
npm run format       # Prettier по всему проекту
```

## Деплой

Статическая сборка (client/dist/) разворачивается на любом статик-хостинге. Поскольку роутинг клиентский (React Router), для прямых переходов по вложенным путям (/works, /artwork/:id и т.д.) нужен SPA-фолбэк — например, на [surge.sh](https://surge.sh) это копия dist/index.html в dist/200.html, создаётся уже после сборки.
